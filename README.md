# AWS ALB Access Log Detections Mod for Powerpipe

Run detections and view dashboards for your AWS Application Load Balancer access logs to monitor and analyze activity across your load balancers using Powerpipe and Tailpipe.

Visit [hub.powerpipe.io/mods/turbot/tailpipe-mod-aws-alb-access-log](https://hub.powerpipe.io/mods/turbot/tailpipe-mod-aws-alb-access-log) for more information.
